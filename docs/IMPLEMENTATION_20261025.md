# OSZ 插件迁移与验证（2026-10-25）

## 1. 边界

输入对象是 `.osz` 压缩包。插件首先调用通用归档枚举，再读取其中的 `.osu` 元数据，返回独立音频成员及对应背景；没有对外的 `.osu` 文本解析入口，也没有独立 `.osu` 歌曲导入能力。

| 位置 | 职责 |
| --- | --- |
| `src/plugin.cpp` | OSZ 路径入口、ABI 协商、包内枚举、读取限制、回调错误和背景字节返回 |
| `src/parser.cpp` | 包内元数据解释、引用路径校验、音频收集与去重、逐音频背景关联 |
| 播放器 `osu_plugin_client.cpp` | 定位并加载 DLL，提供通用归档 I/O 回调，将 ABI 结果转成宿主对象 |
| 播放器导入器／播放源／文件属性 | 使用插件结果添加歌曲；已有解码器播放；内嵌封面优先；压缩包只读 |

播放器保留 `.osz` 后缀识别、打开筛选器、归档成员身份和后缀保护。这些用于格式分派，不保留谱面解析副本。缺少或不兼容的 DLL 会使 OSZ 导入报错，普通 ZIP／RAR 继续使用原有流程。

## 2. 解析规则

1. OSZ 内按归档顺序处理谱面；读取 `[General]` 中的 `AudioFilename`。
2. 接受 UTF-8／BOM、CRLF／LF、数字版本头和带引号的文件名；拒绝无效 UTF-8、NUL 和缺失头信息。
3. 引用相对于所在谱面目录，统一分隔符和 `.`／合法 `..`，匹配不区分大小写，保留归档实际成员名。
4. 禁止越过包根、绝对路径、盘符和 URL。不存在的引用不作为歌曲，不猜测包内任意音频。
5. 不同难度的同一音频只保留一次。多音频全部返回，保持首次引用顺序。
6. 背景只取引用同一音频的谱面首次有效背景；不借用其它歌曲背景。不解析视频和击打音效作为音乐。
7. 封面顺序：音频内嵌封面 → 插件返回的对应背景 → 无封面。

限制：每次最多 256 份谱面、64 MiB 谱面文本；单个元数据或图片成员最多 16 MiB；目录最多 1,048,576 个成员、累计 32 Mi UTF-16 码元、每个名称不超过 32,767 码元。超限或读取失败不返回成功的部分列表。

## 3. ABI 与生命周期

`ttp_osu_query(1, ...)` 返回 `resolve`／`cover`。两者都接受 OSZ 路径，通过宿主提供的 `list_members`／`read_member` 访问压缩包。

- 输出字符串和图片仅在回调期间有效，宿主复制结果。
- 成员读取缓冲区由宿主管理，在下次读取或整个调用结束前有效，插件不释放。
- 调用同步执行，进度和取消继续在调用线程传递；DLL 不启动常驻线程。
- 插件内部异常转为 HRESULT；宿主回调捕获自身异常。CRC、短读、取消和内存不足保留错误码。
- 导入先完整扫描，再交付结果；任一回调失败，宿主丢弃本次结果。
- 播放器只加载 EXE 同目录 `AddIn/ttp_osu.dll`，成功后持有模块，不使用工作目录／PATH 寻找同名文件。

## 4. 构建与兼容

独立 CMake 项目，x86、C++20、VC-LTL／YY-Thunks、体积优化。无新增解码库；使用系统 `kernel32.dll`、`msvcrt.dll` 基础入口。构建时静态检查 XP 和 Win7 导入清单，运行时由宿主协商 ABI。

原版播放器不支持此新增归档 ABI；本项目没有声称恢复原版中不存在的 OSZ 支持。后续如果要支持原版播放器，需要另行设计宿主接入。
