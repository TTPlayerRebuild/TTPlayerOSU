# Sayobot osu! 镜像站接入

当前对应 `ttp_osu 2026.10.28p2`、`ttpbrowser 2026.10.28p9` 和重建版主程序 `2026.10.28p5`。

## 入口与组件边界

配置的 osu! 或 lazer 可执行文件至少一个通过插件安装接口的特征识别，且插件提供下载页接口，才显示「Sayobot osu! 镜像站」。边框右键位于「个人媒体库」后、「选项」前；个人媒体库齿轮菜单在来源列表后追加同名条目。路径失效时同步隐藏并退出已打开的镜像站。

独立导出 `ttp_osu_download_page_query`（序号 6）提供 ABI 2，继续支持 ABI 1 的原始前缀大小：

- `page`：站点名称与首页 `https://osu.sayobot.cn/home`。
- `recognize`：精确识别 OSZ 下载 URL，返回备用文件名。
- `script`（ABI 2）：提供站点适配脚本，宿主复制后交给浏览器。
- `recognize_audio`（ABI 2）：精确识别详情播放使用的完整音频 URL。

主程序先查询 ABI 2，再回退 ABI 1；音乐窗宿主的新增回调逐字段检查 `size`。旧 ABI 1 保留下载页能力，缺少新的脚本和播放接入。脚本不暴露 `window.external.ttplayer` 或个人媒体 RPC。原生端再次检查页面来源、当前页面、插件与游戏身份、消息大小和目标 URL；只允许显式下载及播放操作。

## 下载与文件名

站点卡片的云下载按钮，以及详情页「下载／无视频／mini」，在捕获阶段转入原生队列，使用 `server=auto`。不再受站点详情按钮的下载冷却计时影响。其余临时下载链接仍有锚点、导航、新窗口及浏览器下载事件作为补充入口。

允许的初始地址是准确 HTTPS 域名 `txy1.sayobot.cn` 或 `dl.sayobot.cn` 下的 `/beatmaps/download/{full|novideo|mini}/{非零十进制ID}`。下载由宿主既有 `ttp_https` 流处理重定向和正文。下载目录为空时恢复原生默认目录。

宿主从最终响应读取 `Content-Disposition`，通过 `IStream::Stat` 的名称返回给下载队列，不额外发送请求。优先解码 `filename*`，再回退 `filename`；支持 UTF-8、ISO-8859-1、引号与分号，对 Windows 非法字符作替换，拒绝目录穿越和控制字符。仅曲包下载启用该名称，且仍必须是 `.osz`；缺失或无效时回退为 `Sayobot <sid>[ - novideo| - mini].osz`。普通音乐的命名规则保持原设置。

未开启覆盖文件时，重名文件追加 ` (1)`、` (2)`，最终文件名同步到下载列表及持久记录。同一 URL 的重复点击仍复用已有任务。下载完成不自动安装曲包，也不把 OSZ 加入播放列表。

文件名处理依据：[RFC 6266](https://www.rfc-editor.org/rfc/rfc6266)。本机读取的实际响应示例：`2562231 glass beach - soft!!!!!!.osz`。完整包、无视频包与 mini 包可能返回相同文件名。

## 详情播放与无静音拦截

脚本从站点 `/v2/beatmapinfo` 响应及当前详情的 sid/bid 获取所选难度对应音频，以 `/beatmaps/files/{sid}/{音频文件名}` 构造完整音频地址，并发送歌名、歌手和曲目标识。主程序追加到当前播放列表并立即播放，不用网页预览片段代替完整歌曲。

捕获详情「播放」点击，阻止原站点处理函数，只将完整音频提交给播放器。卡片「试听」及页面播放器的播放/暂停使用浏览器原有播放行为，保留返回的 Promise、错误、静音与音量设置。脚本观察站点脱离 DOM 的 `new Audio()` 试听对象，在详情转入原生播放时暂停已有试听，并优先调用网页可见的暂停按钮同步图标。再次点击试听仍可在网页内播放，不提交播放列表。

p1 曾全局阻止 `HTMLMediaElement.prototype.play`，误伤页面试听；p2 已撤销该全局禁止，仅接管详情按钮。实测 SID 2566051 试听 `currentTime` 正常增长，`paused=false`、`muted=false`、音量保持 `0.5`，暂停/继续、详情转入原生、再次试听均通过。证据为 `ttpbrowser/out/sayobot-preview-20261028p2/live/preview`。

WebView2 使用限于本站顶层页面的脚本与消息通道。IE 在文档完成时注入相同脚本，使用专用导航消息协议；现代第三方站点能否在旧 IE 渲染仍取决于站点，不宣称已在 XP/Win7 完成实测。个人媒体库 WebView2 → IE → 原生回退保持原逻辑。

## 验证与证据

脚本来源快照、插件 ABI 探针、下载队列测试与真实 WebView2 宿主证据位于工作区 `ttpbrowser/out/sayobot-fix-20261028p9`（忽略目录，不随运行包发布）。本次按用户提示扩大隔离测试窗口，避开站点悬浮按钮对下载入口的遮挡，没有删除或修改站点悬浮按钮。

最终结果与运行包信息见音乐窗 [构建验证](../../ttpbrowser/docs/BUILD_VALIDATION.md)。初版 p8 仅由网页播放；当前 p9/p2 保留页面试听，并将详情播放接入主程序。
